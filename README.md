# 605IT — Airbnb EDA London

## Project Title
Exploratory Data Analysis of Airbnb Pricing and Availability Trends in London

## Student
Balihar Singh Sohal | Coventry University | April 2026

## Description
This project investigates pricing patterns and availability trends across 
London Airbnb listings using the Inside Airbnb dataset (96,871 listings).

## Tools Used
- Python 3.13
- pandas, numpy
- matplotlib, seaborn
- scikit-learn
- Jupyter Notebook

## Key Findings
- Entire home listings dominate at 67% of market
- City of London most expensive at £229/night average
- Accommodates is strongest price predictor (r = 0.57)
- Random Forest classifier achieved 91.12% accuracy
- Linear Regression R² = 0.51

## Dataset
Inside Airbnb London — http://insideairbnb.com/get-the-data/
